## 4. 사용자가 수행할 수동 인수 테스트

1. `START_WINDOWS.bat` 실행 → `http://localhost:5173`로 접속한다.
2. 최초 지도 타일이 표시되고 드래그·휠로 확대/축소가 가능한지 확인한다.
3. 지도 임의 위치를 클릭한다 → 해당 좌표에 마커가 표시되는지 확인한다.
4. 왼쪽의 `LAT`, `LNG` 값과 하단 `CURRENT ORIGIN` 값이 갱신되는지 확인한다.
5. 위도 `37.394790`와 경도 `127.111190`을 입력한다 → 판교역 인근으로 이동하는지 확인한다.
6. 위도 `91`, 경도 `127`을 입력한다 → 오류 메시지가 나오는지 확인한다.
7. 키 없는 상태에서 `서울시청`을 검색한다 → 예시 결과가 표시되는지 확인한다.
8. 검색 결과를 선택한다 → 해당 위치에 마커가 표시되는지 확인한다.
9. `내 현재 위치로 지정`을 선택한다 → 권한 허용 시 좌표가 변경되는지 확인한다.
10. 위치 권한을 거부한다 → 오류 안내 후 지도 클릭이 계속 가능한지 확인한다.
11. 화면 너비를 375px 수준으로 축소한다 → 가로 스크롤 없이 지도·입력 폼이 표시되는지 확인한다.
12. 카카오 JavaScript 키를 발급받은 후 `.env`에 입력하고 서버를 재시작한다 → 카카오맵으로 전환되는지 확인한다.
13. 카카오 모드에서 일반 주소 및 장소를 검색하여 1개를 선택한다.

## 5. 결함 발생 시 우선 점검 사항

| 증상 | 점검 항목 |
|---|---|
| `npm` 실행 불가 | Node.js 설치·PATH 설정 확인 |
| 지도 타일이 비어 있음 | 인터넷 연결·OSM 타일 서버 접근 여부 확인 |
| 카카오맵이 로딩되지 않음 | JavaScript 키 타입·JavaScript SDK 도메인 등록·카카오맵 ON 여부 |
| GPS 오류 | HTTPS/localhost 및 위치 권한 상태 확인 |
| 주소 검색 불가 | 개발용 지도에서는 예시 장소만 지원. JS 키 연결 필요 |
| 모바일 지도가 잘림 | 브라우저 캐시 정리, 화면 회전 후 다시 확인 |
