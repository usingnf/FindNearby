## 1. 구현 범위

| 항목 | 완료 범위 |
|---|---|

## 2. 확인된 공식 API·데이터 제약

- 행정안전부 공중화장실정보 데이터셋 설명: 2025년 2월부터 원천데이터의 WGS84 위도·경도 제공 중단 안내. 따라서 주소 기반 위치 확정이 필요함. <https://www.data.go.kr/data/15075531/standard.do>
- 카카오 로컬 주소→좌표 API는 `GET /v2/local/search/address.json`과 REST API 키 인증을 제공하며 주소에 대응하는 경도 X / 위도 Y를 반환함. <https://developers.kakao.com/docs/ko/kakaomap/rest-api>
- 주소 대표 좌표가 출입구 위치임을 보증하지 않으므로 실제 입구·차량 접근점은 별도 확인 데이터를 사용하도록 분리함.

## 4. 미검증 및 한계

1. **공식 원천 CSV 실데이터 적재 미실시** — 현행 파일의 실제 컬럼·건수·인코딩 및 지오코딩 성공률 실측 필요.
2. **카카오 REST API 실호출 미실시** — 인증키 미설정. 요금·무료 제공량·지오코딩 캐시 허용·브라우저 지도 표시 약관 확인 필요.
3. **출입구 실제 데이터 미확보** — 템플릿과 검증 인터페이스는 구현했으나, 시설관리자에게 확인한 실제 출입구·차량 접근점은 등록하지 않음.
4. **전체 React 빌드 및 브라우저 검증 미실시** — 실행 환경에서 npm 레지스트리 DNS 오류(`EAI_AGAIN`) 발생. 핵심 TS 모듈 엄격 검사 및 모든 TS/TSX 구문 검사는 통과.
5. **위치 보정은 보행가능 경로 최적화가 아님** — 등록된 접근점 중 모드 우선/직선거리순으로 선택. 실제 가장 적합한 출입구 판정은 경로 API 비교 및 현장 테스트 필요.
6. **지역 데이터 공백** — 좌표 변환이 누락된 공중화장실은 검색 대상에서 제외. 전국 공공시설 완전성을 보장하지 않음.
7. **개방시간·주차 가용성 보장 불가** — 원천데이터의 보유값을 출처와 함께 안내하는 수준.
8. **운영 미적용** — API 실제 요금 상한/공개서비스 인증/정기 데이터 갱신·개인정보 관련 정책은 8~9단계에서 확정.

## 5. 사용자 PC의 추가 인수 테스트

- [ ] `START_WINDOWS.bat` 실행 후 `http://localhost:5173` 정상 접속
- [ ] 키 없이 기존 가상 지도·후보·추천 동작
- [ ] 위도/경도가 존재하는 CSV를 수입하고 `/api/facilities/status` 에 건수 표시
- [ ] 좌표가 없는 CSV는 지오코딩 허용 전 검색 결과에 노출되지 않음
- [ ] 카카오 REST 키 연결 후 주소 변환 결과와 실제 위치를 샘플 30곳 이상 직접 비교
- [ ] CSV 중복·지오코딩 실패·주소 불일치 행이 중복되거나 잘못 표시되지 않음
- [ ] 실제 검증 출입구 파일을 가져온 후 출입구/차량 접근점에 따라 경로 도착점이 달라짐
- [ ] 카카오 SDK + REST 키를 동시에 연결하고 도보·대중교통·자동차 각각 3개 추천 실행
- [ ] 데이터 출처, 좌표 품질, 개방시간의 주의 안내가 모바일에서 정상 표시
- [ ] API 호출/과금·외부 공급자 이용 조건과 DB 저장 정책 확인

**판정:** 6단계의 구현·자동 테스트는 완료. 실제 데이터 정합성 및 카카오 실호출은 8단계 통합 검증 전 필수 해결 과제.
