## 3. 사용자 PC 수동 인수 시험

- [ ] `START_WINDOWS.bat`를 실행하면 Vite 서버가 열리고 지도가 표시된다.
- [ ] 카카오 키 미설정 상태에서 `OSM DEMO`가 보인다.
- [ ] 지도 클릭 또는 예시 장소 선택 시 출발지 마커와 좌표가 변경된다.
- [ ] 검색 전에는 주변 시설 마커가 없고 결과를 검색하라는 안내가 보인다.
- [ ] 편의점 검색에서 `가상 편의점` 목록과 숫자 마커가 표시된다.
- [ ] 지하철역·공중화장실을 바꿀 때 해당 유형의 가상 목록으로 변경된다.
- [ ] 시설 목록 선택 시 숫자 마커 강조 표시가 변경된다.
- [ ] 시설 마커를 클릭하면 해당 목록의 항목이 선택된다.
- [ ] 초기 반경 500m에서 후보가 부족하면 자동으로 범위가 확대된다.
- [ ] 출발지 변경 시 이전 시설 데이터가 제거되고 자동 재검색된다.
- [ ] 좌표 직접 입력, GPS 오류, 주소 예시 검색 등 2단계 기능이 유지된다.
- [ ] 화면 폭 375px에서도 입력 폼과 지도가 겹치지 않는다.
- [ ] 카카오 JavaScript 키를 연결하면 카카오맵과 실제 시설 검색으로 전환된다.
- [ ] 카카오에서 반환한 이름, 주소, 직선거리가 결과 목록에 표시된다.
- [ ] 카카오 API 연결 오류 시 오류 안내 및 예외 처리가 정상 동작한다.

## 4. 3단계 인수 기준

### 완료된 구현 범위

1. 시설 유형 3개 선택
2. 출발지 주변 시설 후보 검색 모듈
3. 자동 검색 반경 확대 및 최대 15개 후보 처리
4. 후보별 직선거리 계산·정렬·중복 제거
5. 지도 마커와 시설 목록의 선택 연동
6. 키 미설정 시 가상 시설 데모 모드
7. 출발지/시설/반경 변경 시 자동 재검색 및 낡은 응답 무시
8. API 오류 및 결과 없음 상태 표시

### 완료로 오해하면 안 되는 부분

- 현재 거리는 **직선거리**이며 실제 이동거리나 최단시간이 아닙니다.
- 실제 근처 **3개 최적 시설** 선정은 5단계의 경로 비교 이후에 판정합니다.
- 공중화장실은 키워드 기반 임시 검색이며 실제 개방 여부를 보장하지 않습니다.
- 가상 데모 데이터는 실제 시설을 뜻하지 않습니다.
- 모든 후보가 실제 API 검색 인덱스의 전체 시설을 대표한다는 보장은 없습니다.
- 카카오 실호출은 자격증명 및 허용 도메인 등록 뒤에만 검증할 수 있습니다.

## 5. 기술 검증에 필요한 후속 조치

1. 사용자 Windows PC에서 `npm install`, `npm run typecheck`, `npm run build`, `npm run dev` 실행
2. API 키 없이 데모 화면이 표시되는지 확인
3. 카카오맵 JavaScript 플랫폼 키를 `.env`의 `VITE_KAKAO_JS_KEY`에 설정하고 허용 도메인 등록
4. 3개 시설 타입으로 카카오 실제 검색 호출을 진행
5. 실제 검색 결과와 지도 표시의 위치 정합성을 여러 도시에서 점검
6. 이용량·요금·응답시간 측정 및 개발 요구사항 재평가
