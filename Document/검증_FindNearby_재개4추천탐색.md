# FindNearby 재개 4단계 추천 탐색 검증

검증일은 2026년 11월 8일이다. 후보의 경로를 평가하면서 페이지와 반경을 순차적으로 탐색하고, 검색을 멈춘 이유를 결과와 함께 반환하도록 구현했다. [추천 정책과 공통 응답 설계](설계_FindNearby_추천정책및응답형식.md)

## 구현 결과

- 도보는 500m, 대중교통·자동차는 2km에서 시작한다. 시설 대표 좌표와 ID로 순서를 정하고, 첫 10개를 처리한 뒤 미평가 후보·다음 페이지·다음 반경을 이어서 조회한다. 앞선 후보에 유효 경로가 3개 이상 있어도 다음 후보의 경로로 순위가 바뀔 수 있다.
- 같은 검색에서 이미 본 시설 ID는 다시 평가하지 않는다. 시설 대표 좌표와 모드별 접근점을 구분해 경로 계산에 사용한 도착점을 응답에 포함한다. 출발 좌표와 도착 좌표가 같으면 경로 없음으로 처리한다.
- 자동차는 실제 도착점이 10km 이내인 후보를 묶어 요약을 조회한다. 배치 응답에 없거나 범위 밖인 후보는 남은 예산 내에서 단건으로 조회한다. 자동차 카드는 요약을 유지하고, 선택한 시설의 상세 경로와 조회 시각은 상세 영역에 표시한다. [카카오모빌리티 다중 목적지](https://developers.kakaomobility.com/guide/navi-api/destinations)
- 응답은 찾은 후보 수, 평가 완료 수, 경로 없음, 조회 실패, 마지막 반경과 중단 이유를 함께 전달한다. 서버가 호출량·시간 제한을 만났거나 이후 페이지 조회에 실패해도 앞서 확보한 결과를 반환한다. 화면은 조건이 바뀌면 이전 응답과 상세 경로를 지운다.
- 주소 검색·시설 검색·경로·재시도와 상세 조회는 호출을 보내기 전에 같은 SQLite 사용량 장부에서 차감한다. 분당·일일 한도 확인과 호출 기록은 하나의 트랜잭션으로 처리한다. 같은 장부를 사용하는 프로세스에 한도가 적용되며, 장부에는 호출 시각과 API 경로만 기록한다.

## 검증 결과

| 항목 | 결과 |
| --- | --- |
| Python 자동 테스트 | 기존 10건과 추가 회귀 테스트 10건 통과 |
| 추가 후보 | 처음 10개에서 유효 경로 2개만 나올 때 다음 페이지에서 3개 확보. 처음부터 유효 경로가 충분해도 다음 반경의 더 짧은 경로가 상위로 이동 |
| 순위와 예외 | 세 모드 시설 ID 동률 정렬, 대중교통 도보거리 동률 기준, 동일 좌표, 자동차 배치 누락·10km 밖 단건 처리, 페이지 오류와 호출 한도에서 부분 결과 유지 확인 |
| 지속 한도 | 별도 Python 프로세스 두 개가 같은 DB를 사용해 앞 프로세스의 호출을 다음 프로세스가 합산. 동시 차감과 UTC 자정 경계의 최근 60초 한도 확인 |
| 시간과 재시도 | 기한이 지난 호출의 차단, 일시 오류 후 재시도의 사용량 차감 확인 |
| 프런트엔드 | 전체 타입 검사와 Vite 빌드 통과. Edge에서 도보→자동차→도보 전환 시 이전 응답 미표시와 부분 결과 안내 확인 |
| 실제 자동차 | 서울시청 주변 편의점 검색에서 45곳 평가, 호출 한도에서 상위 3곳 반환, 카카오 지도에서 상세 경로선 확인. 요약에 반환한 도착점과 상세 요청 좌표 일치 확인 |
| 사용량 DB 접근 | 개발 서버에서 실제 테스트용 SQLite 파일 URL 요청이 HTTP 403으로 차단됨 |

## 종료 기준과 남은 검증

공개 도보 API 규격은 도로 연결을 찾지 못한 상태와 결과 경로를 설명한다. 요청 좌표가 경로에 연결될 때 이동할 수 있는 최대 거리의 보장을 확인할 수 없어, 직선거리는 후보 순서에 사용하고 조기 종료는 반경·호출량·시간 예산을 기준으로 적용했다. [카카오 도보 경로 규격](https://developers.kakao.com/docs/ko/kakaomap/rest-api)

검색별 기본 설정은 최대 12회와 8초다. 서버는 외부 요청을 시작하기 전 남은 시간을 확인하고 개별 HTTP 단계의 대기 시간을 제한한다. 전체 응답 시간은 외부 응답 전송과 화면 처리 시간에 영향을 받으므로 P95 10초 목표는 8단계에서 별도로 실측한다. 카카오 지도 SDK의 브라우저 요청은 카카오 앱 쿼터에서 확인한다. [개발 실행과 한도 설정](../Dev/안내_FindNearby_개발실행.md)
