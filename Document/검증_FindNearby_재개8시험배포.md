## 시험 운영 조건

- 서버는 루프백에서 워커 1개로 실행했다. HTTP 요청 제한과 SQLite의 카카오 REST 호출 제한을 별도로 적용한다. 운영 담당자는 외부 시험 주소가 생기면 게이트웨이에서 시험자 접근 범위를 제한하고 신뢰할 프록시를 지정한다. [Uvicorn 설정](https://github.com/encode/uvicorn/blob/master/docs/settings.md)
- 시험 운영에서는 브라우저 검색 P95 10초 초과, 최근 5분 내 5xx 또는 429가 3건 이상 반복되거나 일일 호출량이 설정 상한의 80%에 도달하면 원인을 확인한다. 요청 로그는 작업명·HTTP 상태·처리 시간만 남기며, 시험 운영 기준 보관 기간은 7일이다. 시설과 접근점의 기준일·출처는 자료 갱신 때 확인한다.
- 카카오 앱의 사용자 제공 화면에서 유료 API는 비활성 상태였고, 서버 REST 한도와 브라우저 지도 SDK 사용량은 따로 확인한다. 운영 전 자동차 API 이용 조건, 실제 호스팅·도메인 비용과 운영 예산을 확정한다. [카카오 쿼터](https://developers.kakao.com/docs/ko/getting-started/quota) · [카카오모빌리티 가격](https://developers.kakaomobility.com/price/)

## 외부 시험에 필요한 항목

시험자가 접속할 비공개 HTTPS 주소가 확보되면 게이트웨이와 신뢰받는 인증서를 구성하고, 해당 주소를 카카오 지도 JavaScript SDK 도메인에 등록한다. 이어서 Safari와 실제 iOS·Android 기기에서 위치 권한 허용·거부, 목록·지도 전환, 시설 검색과 세 경로를 확인한다. 외부 주소의 접근 제한, 운영 예산과 공개 범위도 이때 확정한다.
