# FindNearby 재개 2단계 공개 자료와 실연동 검증

검증일은 2026년 11월 8일이다. 공중화장실 원본 파일과 가져오기, 공개 API 이용 조건을 확인했다. 로컬 키와 개발 도메인 설정 후 실제 지도·주소·시설·경로 연동을 확인했다.

## 카카오 API 키 설정

1. 카카오디벨로퍼스에서 앱을 선택하거나 만든다. 앱 관리의 **카카오맵 → 사용 설정**에서 상태를 **ON**으로 설정한다. 앱 정보의 **카카오맵 무료 쿼터** 배지와 **통계 → 쿼터**를 확인한다. [카카오맵 사용 설정](https://developers.kakao.com/docs/ko/kakaomap/common)
2. **앱 → 플랫폼 키 → JavaScript 키**에서 **JavaScript SDK 도메인**에 개발 화면 주소 `http://127.0.0.1:5173`을 등록한다. 브라우저에서도 이 주소로 접속한다. [플랫폼 키 설정](https://developers.kakao.com/docs/ko/app-setting/app), [지도 SDK 가이드](https://apis.map.kakao.com/web/guide/)
3. 같은 플랫폼 키 메뉴의 **REST API 키**를 복사한다. 호출 허용 IP를 설정한 경우 실제 외부 요청을 보내는 서버의 공인 IP를 등록한다. 자동차는 별도 키를 쓰는 경우에만 해당 키를 추가로 준비한다. [플랫폼 키 설정](https://developers.kakao.com/docs/ko/app-setting/app), [카카오모빌리티 시작하기](https://developers.kakaomobility.com/guide/navi-api/start)
4. PowerShell에서 `Dev`를 열고 아래처럼 `.env`를 준비한다. 키 값은 로컬 파일에 직접 입력한다. 브라우저로 전달되는 `VITE_` 변수에는 JavaScript 키만 사용한다. [프로젝트 환경변수 양식](../Dev/.env.example)

```powershell
if (-not (Test-Path -LiteralPath .env)) {
    Copy-Item -LiteralPath .env.example -Destination .env
}
notepad .env
```

| 변수 | 입력할 값 |
| --- | --- |
| `VITE_KAKAO_JS_KEY` | 앱의 JavaScript 키 |
| `KAKAO_REST_API_KEY` | 주소·시설·도보·대중교통을 호출할 서버용 REST API 키 |
| `KAKAO_MOBILITY_REST_API_KEY` | 자동차용 REST API 키가 별도일 때만 입력. 비워두면 기본 REST 키를 사용 |

API 서버와 웹 개발 서버를 다시 시작한다. 상태 응답의 `live_ready: true`는 REST 키가 설정됐음을 뜻한다. 웹 화면의 **실제 데이터** 표시와 함께 지도, 주소 검색, 경로 조회가 각각 성공하는지 확인한다. [개발 실행 안내](../Dev/안내_FindNearby_개발실행.md), [로컬 상태 확인](http://127.0.0.1:5173/api/status)

## API별 이용 조건

아래 숫자는 공개 가격표 기준이며 실제 무료 적용과 유료 설정은 앱에서 확인한다. 카카오맵 무료 쿼터는 개발자 계정에서 카카오맵을 처음 활성화한 앱에 적용된다. 두 번째 이후 앱 또는 무료량 초과 사용은 카카오맵 문서의 비즈월렛 연결과 유료 API 설정 조건을 따른다. [카카오맵 이용 정책](https://developers.kakao.com/docs/ko/kakaomap/common), [유료 API 설정](https://developers.kakao.com/docs/ko/app-setting/paid-api)

| API | 공개 일일 무료량 | 공개 초과 단가 |
| --- | ---: | ---: |
| 카카오맵 웹 SDK | 300,000건 | 0.1원/건 |
| 주소→좌표 | 100,000건 | 0.5원/건 |
| 카테고리·키워드 검색 | 각각 100,000건 | 2원/건 |
| 도보·대중교통 | 각각 1,000건 | 10원/건 |
| 자동차 단건 | 10,000건 | 해당 가격 구간 8원/건 |
| 자동차 다중 목적지 | 1,000건 | 해당 가격 구간 20원/건 |

[카카오 쿼터](https://developers.kakao.com/docs/ko/getting-started/quota), [카카오모빌리티 쿼터·가격](https://developers.kakaomobility.com/price/)

- **공중화장실 좌표**는 저장·재사용 권한이 있는 공공 좌표 원본으로 구축한다. 카카오는 공공 주소를 입력하더라도 Local API가 반환한 좌표를 공용 시설 DB에 저장해 반복 사용하는 방식을 허용하지 않는다고 안내했다. 좌표 없는 행은 제외하거나 필요 시 조회하는 방식과 별도 저장 허용 출처를 검토한다. [공중화장실 좌표 저장에 관한 카카오 답변](https://devtalk.kakao.com/t/local-api-db/152489)
- **지도와 경로**는 요청한 화면에서 표시하고 원본 응답을 공용 캐시나 DB에 보관하는 설계는 제외한다. 카카오는 대중교통 단일 호출 결과를 해당 안내 동안 메모리에 유지한 뒤 폐기하는 사례를 허용한다고 답변했다. 로컬 REST 결과와 타사 지도를 조합하는 것에 대한 답변은 자동차 길찾기의 별도 표시·재사용 조건으로 확대 해석하지 않는다. 현재 제품은 실제 추천을 카카오 지도에 표시하며 로고와 저작권 표기를 유지한다. [카카오 운영정책](https://developers.kakao.com/terms/ko/site-policies), [대중교통 응답의 임시 사용](https://devtalk.kakao.com/t/api/151736), [타사 지도 표시 답변](https://devtalk.kakao.com/t/local-api/151190)
- **상업 이용과 자동차**는 서비스 운영 자체와 API 재판매·별도 과금을 구분한다. 카카오맵은 약관을 준수하는 상업 서비스 이용을 별도로 제한하지 않지만 API 재판매와 API 기능 자체의 별도 과금에 제한이 있다. 자동차 응답의 장기 저장·재배포·별도 과금에 적용되는 구체적인 조건은 카카오모빌리티 공개 기술 문서와 가격표에서 확정하지 못했다. 앱의 실제 계약 및 이용 조건을 운영 전에 확인한다. [카카오맵 FAQ](https://devtalk.kakao.com/t/faq-api/125610), [카카오모빌리티 안내](https://developers.kakaomobility.com/guide/navi-api/start), [가격 및 문의](https://developers.kakaomobility.com/price/)
- **자동차 다중 목적지**는 최대 30개와 10km 반경을 지원하며 거리·시간 요약을 반환한다. 지도에 그릴 경로는 단건 상세 조회로 검증한다. [다중 목적지 규격](https://developers.kakaomobility.com/guide/navi-api/destinations), [단건 길찾기 규격](https://developers.kakaomobility.com/guide/navi-api/directions)

## 실연동 결과

Edge에서 개발 주소의 카카오 지도 SDK가 HTTP 200을 반환하고 지도 타일이 화면에 표시됐다. 지도 클릭으로 출발지를 지정하고, 서울 중구 세종대로 110을 실제 주소로 검색해 선택했다. 자동차 기준 편의점 추천 3건과 1위 상세 경로선을 확인했으며, 2위 선택 시 상세 경로와 선택 표시가 갱신됐다.

개발 주소 등록 전에는 카카오 SDK가 도메인 불일치로 HTTP 401을 반환했다. JavaScript SDK 도메인에 `http://127.0.0.1:5173`을 등록한 뒤 같은 브라우저에서 다시 확인했다. [카카오 플랫폼 키 설정](https://developers.kakao.com/docs/ko/app-setting/app)

| 검증 항목 | 실제 응답 |
| --- | --- |
| 주소 검색 | FindNearby 주소 API HTTP 200, 유효 좌표 1건 |
| 시설 검색 | 서울시청 주변 2km에서 편의점 15건, 지하철역 15건, 공중화장실 4건. 카카오 API HTTP 200 및 좌표 범위 확인 |
| 도보 | FindNearby 경로 API HTTP 200, 3,929m, 3,819초, 경로점 137개 |
| 대중교통 | FindNearby 경로 API HTTP 200, 4,845m, 1,477초, 경로점 83개, 도보·버스·지하철 구간, 환승 2회 |
| 자동차 | FindNearby 경로 API HTTP 200, 4,725m, 711초, 경로점 86개 |
| 자동차 다중 목적지 | 카카오모빌리티 HTTP 200, 거리와 시간이 있는 경로 요약 2건 |

도보·대중교통·자동차는 판교역과 성남시청 인근의 같은 공개 좌표를 사용했다. 브라우저 경로선과 추천 선택 검증은 자동차 모드에서 수행했다. 시설 검색 건수는 각 API의 첫 페이지를 기준으로 기록했다.

키를 로컬 `Dev/.env`에 설정했다. 개발 서버에서 `/ApiKey.txt`와 `/.env` 요청이 HTTP 403을 반환하고 브라우저에 제공되는 앱 코드에 REST 키가 포함되지 않는 것을 확인했다.

## SRS 기술 검증 상태

| SRS 13절 항목 | 현재 결과와 확인할 내용 |
| --- | --- |
| 1. 앱·인증키 | JavaScript·REST 키 인증과 개발 도메인 확인. 앱 콘솔 적용 쿼터는 확인 필요 |
| 2. 지도 SDK | 실제 지도 타일, 출발지 선택 확인 |
| 3. 편의점·지하철역 | 실제 카테고리 검색과 좌표 확인. 편의점은 브라우저 추천·경로 표시까지 확인 |
| 4. 공중화장실 | 실제 키워드 검색, 지역 원본 적재·반경 조회 확인. 전국 파일 및 실제 장소 정합성은 확인 필요 |
| 5. 도보 | 실제 경로 좌표, 거리, 소요시간 응답 확인 |
| 6. 대중교통 | 실제 경로 좌표, 도보·버스·지하철 구간과 환승 응답 확인 |
| 7. 자동차 | 단건 상세 응답, 다중 목적지 요약, 브라우저 경로선과 추천 선택 확인 |
| 8. 도착점 보정 | 검증된 접근점을 가져온 후 모드별 목적지 좌표 대조 |
| 9. 표시·저장 조건 | 카카오맵 공개 정책 확인. 모빌리티의 구체 계약 조건은 확인 필요 |
| 10. 쿼터·비용 | 공개량·단가 확인. 앱별 적용량과 실제 호출 비용은 확인 필요 |

도보·대중교통 경로선의 브라우저 검증과 경로 없음·429 안내의 실연동 시험은 통합 검증에서 진행한다. 이 실연동 시험 당시 개발 서버 한도는 프로세스당 분당 12회와 기본 일일 50회였다. 재개 4단계에서 재시작 후에도 한도가 유지되도록 변경했다. [기존 개발 계획](계획_FindNearby_기존검토및후속개발.md), [재개 4단계 검증](검증_FindNearby_재개4추천탐색.md)
