## 실제 API 예비 시험

실제 FastAPI 검색·상세 엔드포인트에서 카카오 실응답을 확인했다. 검색당 12회·8초, 최근 60초 12회, UTC 일일 50회 기본 설정과 별도 시험용 사용량 장부를 사용했다. 이동수단 사이에 61초 간격을 뒀다. 시간은 로컬 API 요청부터 응답까지의 참고값이다.

| 시나리오 | 시설 검색 | 경로 조회 | 합계 | API 결과 | 소요 |
| --- | ---: | --- | ---: | --- | ---: |
| 인천 석바위시장 부근 · 도보 공중화장실 | 키워드 2회 | 도보 10회 | 12회 | HTTP 200 · 10곳 평가 · 추천 3개 · 경로선 제공 | 0.610초 |
| 서울시청 · 대중교통 지하철역 | 카테고리 1회 | 대중교통 11회 | 12회 | HTTP 200 · 11곳 평가 · 경로 없음 1곳 · 추천 3개 · 경로선 제공 | 2.719초 |
| 서울시청 · 자동차 편의점 | 카테고리 5회 | 다중 목적지 6회 | 11회 | HTTP 200 · 45곳 평가 · 추천 3개 · 거리·시간 요약 제공 | 0.671초 |
| 자동차 1위 상세 | 0회 | 자동차 단건 1회 | 1회 | HTTP 200 · 상세 경로선 제공 | 0.047초 |

총 36회로 사용량 장부와 일치했다. 외부 호출 실패와 재시도는 각각 0회였다. 추천 3건 모두 검색이 호출 한도에서 끝났고, 평가가 끝난 후보의 추천을 반환했다. 화면까지의 P95와 동시 사용자 성능은 재개 7-3에서 측정한다.

## 무료 사용 범위와 본시험 일정

사용자가 제공한 앱 일간 쿼터 캡처 기준이다. 잔여량은 표시된 쿼터에서 사용량을 뺀 값이다.

| 항목 | 사용량 | 일간 쿼터 | 캡처 시 잔여량 |
| --- | ---: | ---: | ---: |
| 지도 네이티브 SDK | 12 | 300,000 | 299,988 |
| 주소로 좌표 변환 | 45 | 100,000 | 99,955 |
| 키워드 장소 검색 | 5 | 100,000 | 99,995 |
| 카테고리 장소 검색 | 21 | 100,000 | 99,979 |
| 대중교통 경로 조회 | 57 | 1,000 | 943 |
| 도보 경로 조회 | 22 | 1,000 | 978 |
| 자동차 길찾기 | 6 | 10,000 | 9,994 |
| 다중 목적지 길찾기 | 9 | 1,000 | 991 |

- 무료 API만 사용하는 저사용량 시험으로 진행한다. 캡처에 표시된 지도 항목은 네이티브 SDK다. 본시험 시작 전에 앱 콘솔에서 웹 JavaScript SDK의 사용량과 월간·일간 무료 잔여량을 확인한다. 무료분을 소진하면 유료 호출로 전환되지 않도록 유료 API 설정도 확인한다. [카카오 쿼터](https://developers.kakao.com/docs/ko/getting-started/quota) · [카카오모빌리티 쿼터·가격](https://developers.kakaomobility.com/price/)
- **개발 기본 한도 기준으로 하루에 출발지 1곳, 추천 3개 조합**을 실행한다. 조합당 추천 최대 12회와 필요 시 선택 경로 상세 1건의 최대 2회 시도까지 합쳐 일일 최대 42회로 계획한다. 나머지 8회는 주소 검색 등 보충 확인과 여유분이다. 기존 호출이 있으면 그만큼 시험량을 줄이고, 다음 조합은 최근 60초 사용량이 충분히 줄어든 뒤 시작한다. 개발 일일 한도는 한국 시각 오전 9시에 집계일이 바뀐다. 주소·지도 조작과 여러 카드 선택 시험은 별도 예산으로 집계한다.
- 초기 90개 기준은 **30시험일**이었다. 범위를 15개로 줄인 뒤 최초 4개와 추가 11개를 실행했다. 추가 실행은 사용자 승인으로 시험 서버에 일일 상한 500회를 일시 적용해 같은 집계일에 마쳤다. [7-2 실연동 결과](검증_FindNearby_재개7-2화면인수시험.md#2026-11-09-추가-실연동)

### 재개 7-2 기록 항목

`시험 ID / 실행 시각 / 브라우저·기기 / 추천 개수 / 후보·평가 수 / 중단 사유 / 경로선·상세 확인 / 외부 호출·재시도 / 판정 / 근거`를 남긴다. 테스트마다 데모 여부와 적용한 호출 한도를 확인한다. 위치는 공개 시험 출발지 ID로 기록하고 실제 API 응답은 호출 수·시간·상태 등 집계만 남긴다.
